# c-sharp_front-react

essai en vibecoding avec jules (Google) de la création d'un back en c# (.NET Framework 4.8) et d'un front en React Typescript.

## Backend (.NET 4.8)
Le backend est configuré pour cibler .NET Framework 4.8 (`net48`) avec OWIN Self-Host et ASP.NET Web API.

Pour compiler le backend :
```bash
dotnet build backend
```
